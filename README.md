# ⏱️ TimeHits60

TimeHits60 is a simple web application that I built to practice my JavaScript skills and understand how time-based features work in real time. The idea behind this project is very basic — combine a live digital clock and a stopwatch in one place — but while building it, I focused more on learning how things work rather than just finishing the project quickly.

The app has two main sections: a clock and a stopwatch. You can switch between them using tabs, so everything stays clean and easy to use without opening different pages.

The clock shows the current time in hours, minutes, and seconds. It also includes an AM/PM indicator and a small date display. The time updates automatically every second using JavaScript, so it always stays accurate. While building this part, I learned how to use the Date object and how to format time properly, especially converting from 24-hour format to 12-hour format.

The stopwatch is the second part of the app. It has three basic controls: start, stop, and reset. When you start the stopwatch, it begins counting time in minutes, seconds, and milliseconds. When you stop it, the time pauses, and you can continue again if needed. The reset button brings everything back to zero. I used setInterval to update the stopwatch continuously and clearInterval to stop it when needed. This helped me understand how repeated functions work in JavaScript.

One thing I focused on was making the buttons behave properly. For example, when the stopwatch is running, the start button hides and the stop button appears. When it is stopped, the reset button becomes active. These small details make the app feel more natural and user-friendly.

I used only HTML, CSS, and JavaScript to build this project. I did not use any frameworks or libraries because I wanted to practice the basics and improve my core understanding. Writing everything from scratch helped me learn how to structure code better and keep things organized.

The design of the app is simple and clean. I didn’t add too many colors or effects because I wanted to keep the focus on functionality. The layout is easy to understand, and switching between the clock and stopwatch is smooth. Even though the design is minimal, it still looks neat and usable.

While working on this project, I learned a lot of useful things. I got better at working with time in JavaScript, handling intervals, updating the DOM, and managing user interactions. I also understood how important it is to write clean and readable code, even for small projects.

This project may look small, but it helped me build a strong base. It gave me confidence to work on more advanced projects in the future. There are also many things I can improve, like adding a lap feature in the stopwatch, improving the design, or making it more responsive for mobile devices.

Overall, TimeHits60 is a simple but meaningful project for me. It shows my understanding of basic JavaScript concepts and my ability to build something functional from scratch. I plan to keep improving it and build more projects like this as I continue learning.
